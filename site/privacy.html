Privacy Policy

English

Case Converter for TerraMaster TOS is a fully local, offline application. Everything it does happens inside the Docker container on your own NAS.

  • Your text is never uploaded. Case conversion and the word/character count run in your browser (JavaScript) and the text is never sent to the NAS, to us, or to any third party.
  • No analytics, no advertising, no tracking. The upstream website uses Google Analytics and Google AdSense; both have been removed from this TOS edition. The container makes no outbound network connections while you use it.
  • No cookies, no accounts. The application has no login, no user profile and sets no cookies.
  • No personal data is collected or stored. The application keeps no database and no access log of your input.
  • Network access. The only network activity is the one-time image download performed by the TOS App Center when you install the application (the nginx container image from Docker Hub). After that the app works offline.

The application embeds the static, MIT-licensed Case Converter web page (github.com/caseconverter/caseconverter). If you have any question about this policy, please open an issue at github.com/Moechz/caseconvert/issues.

简体中文

Case Converter for TerraMaster TOS 是一个完全本地、离线的应用， 所有处理都在您自己 NAS 上的 Docker 容器内完成。

  • 文本不会上传。大小写转换与字数统计在您的浏览器内（JavaScript） 完成，文本不会发送到 NAS、我们或任何第三方。
  • 无统计、无广告、无追踪。上游网站使用 Google Analytics 与 Google AdSense，本 TOS 版本已全部移除；使用过程中容器不发起任何对外连接。
  • 无 Cookie、无账号。本应用没有登录、没有用户资料，也不设置 Cookie。
  • 不收集、不存储任何个人数据。应用不保存数据库，也不记录您的输入。
  • 网络访问。唯一的网络活动是安装时 TOS 应用中心从 Docker Hub 下载 nginx 镜像；此后应用可完全离线运行。

本应用内嵌 MIT 许可的静态 Case Converter 网页 （github.com/caseconverter/caseconverter）。 如有疑问，请在 github.com/Moechz/caseconvert/issues 提出。
